# Landmass Generator

Projeto de aprendizado em Unity, baseado na série **Procedural Landmass Generation** de [Sebastian Lague](https://www.youtube.com/@SebastianLague), com modificações próprias (terreno infinito, UI, build WebGL, câmera fly, etc.).

Não é um produto — apenas estudo e experimentação publicados no portfólio.

## Créditos

Este repositório parte do conceito e da estrutura ensinados por **Sebastian Lague** na playlist:

- [Procedural Landmass Generation (playlist)](https://www.youtube.com/playlist?list=PLFt_AvWsXl0eBW2EiBtl_sxmDtSgZBxB3)
- [Repositório oficial da série](https://github.com/SebLague/Procedural-Landmass-Generation)

O código original da série está sob [licença MIT](https://github.com/SebLague/Procedural-Landmass-Generation/blob/master/LICENSE) (Sebastian Lague).

## Requisitos

- Unity 6 (projeto criado com 6000.0.40f1)
